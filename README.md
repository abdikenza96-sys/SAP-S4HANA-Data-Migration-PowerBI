# SAP S/4HANA Data Migration & Financial Reporting with Power BI

## 📌 Project Overview
This project simulates the extraction of financial data from SAP S/4HANA (Universal Journal ACDOCA), applies automated data quality checks using Excel/VBA, and delivers a financial dashboard in Power BI.

## 🛠️ Technologies Used
- **ERP:** SAP S/4HANA Cloud Public Edition (Fiori interface)
- **Data & Automation:** Excel, VBA (reconciliation and anomaly detection macros)
- **Business Intelligence:** Power BI (DAX, data modeling, visualization)

## 🔄 Workflow
1. Define chart of accounts and cost centers in SAP S/4HANA.
2. Simulate extraction of the `ACDOCA` table (200+ accounting entries).
3. Run VBA scripts to detect duplicates, imbalances, and outliers.
4. Clean and validate the dataset for analysis.
5. Build KPIs and dashboards in Power BI.
